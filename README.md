# 床邊待辦 Bedside Todo

病房各床待辦事項筆記 PWA——給查房/走廊上被交辦事項時快速記錄用。

- 每床一張卡片,點開快速新增待辦(含常用片語:開 order、抽血、照會⋯)
- 有待辦的床顯示琥珀色標記與數量徽章,完成打勾留時間戳
- 床位名單可逐床編輯,或從醫令系統複製名單整批貼上匯入
- **所有資料(床位、姓名、待辦)只存在使用者手機的 localStorage,不上傳、此 repo 不含任何病人資料**
- PWA:可安裝到主畫面、離線可用
